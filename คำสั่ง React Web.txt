1.ลง Vite เพื่อใช้ React
npm install -g create-vite

2.สร้างโปรเจค React
npm create vite@latest nexstore -- --template react

3.คำสั่งรัน Web
npm run dev


** ตั้งค่า Tailwind CSS ใน React **
1.ลง TailwindCSS
npm install tailwindcss @tailwindcss/vite

2. ตั้งค่า TailwindCSS ใน vite.config.js
// เพิ่ม
import tailwindcss from '@tailwindcss/vite';

// เพิ่มลงใน plugins
export default defineConfig({
   plugins: [
      react(),
      tailwindcss(),  // เพิ่มตรงนี้
   ],
})

3.นำเข้าในไฟล์ src/index.css
@import "tailwindcss";
